# LP-7

Bootstrap を使った画像ギャラリー系の静的サイトです。

## 概要

HTML と CSS のみで構成された静的サイトです。Bootstrap をベースにレイアウトを組み、風景写真(fire / mountains / photograph)を使ったギャラリー表示を実装しています。

## 技術スタック

- HTML / CSS
- Bootstrap
- jQuery

## ディレクトリ構成

```
.
├── index.html            # メインページ
├── bootstrap.css / bootstrap.min.css  # Bootstrap スタイルシート
├── bootstrap.min.js
├── jquery-3.3.1.slim.min.js
├── popper.min.js
├── Untitled-1.css         # 独自スタイル
└── 画像ファイル(fire / mountains / photograph 各種)
```

## 開発

特別なビルド環境は不要です。`index.html` をブラウザで直接開けば表示を確認できます。
